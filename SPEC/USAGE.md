# Инструкция по использованию

Бот — каталог вселенной Звёздных войн. Своих каталожных данных он не хранит: списки и карточки читаются из SWAPI, фото подставляются по тому же числовому `id`. Язык интерфейса и подписей — RU или EN, выбор хранится в памяти процесса на пользователя.

## Старт

1. Откройте бота в Telegram и нажмите **Start** (или отправьте `/start`).
2. Появится постоянная клавиатура и короткое приветствие на языке Telegram (`ru*` → русский, иначе английский), пока пользователь не выберет другой.
3. Команда `/menu` возвращает к выбору раздела.

## Язык

| Кнопка | Что делает |
|---|---|
| Язык / Language | Показывает выбор **Русский** / **English** |

После выбора бот запоминает язык для этого Telegram user id, пересылает клавиатуру и дальше отвечает на выбранном языке: меню, ошибки, подписи полей, названия сущностей, значения карточки (включая вступления фильмов) и кнопки связей.

Источник фактов по-прежнему SWAPI (английский JSON). Перевод — слой отображения, не вторая база.

## Разделы

| Кнопка | Что открывается |
|---|---|
| Фильмы | Список фильмов |
| Персонажи | Список персонажей |
| Поиск персонажей | Запрос имени, затем список совпадений |
| Планеты | Список планет |
| Виды | Список разумных и иных видов |
| Звёздные корабли | Корабли (имя берётся из transports) |
| Транспорт | Общий транспортный каталог |
| Техника | Наземная и атмосферная техника |
| Меню / Menu | Подсказка и та же клавиатура |
| Язык / Language | Выбор русского или английского |

На странице списка — до **8** пунктов. Стрелки « и » листают страницы, в центре — номер `текущая/всего`.

## Карточка

Нажатие на элемент списка присылает:

- фото (если Visual Guide отдаёт картинку для этого `id`);
- подпись с полями сущности;
- если текст не влез в 1024 символа подписи — продолжение отдельным сообщением;
- кнопки связанных сущностей (фильмы персонажа, жители планеты и т.д.) и **Меню**.

Если картинки нет (404 у Visual Guide) или Telegram не смог её загрузить, приходит только текст.

## Поиск персонажей

1. Нажмите **Поиск персонажей**.
2. Бот просит имя и включает ответ (Force Reply).
3. Ответьте на это сообщение текстом, например `Luke` или `Люк`.
4. Пустой результат: «Ничего не найдено» / «Nothing found» и клавиатура меню.

Искать можно только персонажей — у SWAPI нет поиска по другим разделам. На русском языке запрос сопоставляется с локализованными именами и уходит в SWAPI английским именем.

## Связи

На карточке кнопки ведут:

- к **одной** связанной сущности (родная планета, вид персонажа);
- к **списку** (персонажи фильма, пилоты корабля и т.д.).

Из списка связей можно открыть карточку и вернуться кнопкой **Назад**.

## Ошибки

Если SWAPI не ответил или превысил 8 секунд, бот напишет, что справочник недоступен, и предложит **Повторить** или **Меню**. Неизвестные команды — подсказка открыть `/start`.
